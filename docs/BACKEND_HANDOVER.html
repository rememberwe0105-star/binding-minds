3. ⚡ 게이트 패턴 — 남은 작업을 사이트에서 바로 확인

미구현 기능의 버튼은 전부 실제 엔드포인트를 먼저 호출하도록 배선되어 있습니다. 미구현이면 "Backend integration pending" 다이얼로그에 필요한 METHOD /path와 요청서 번호가 표시되고, 엔드포인트가 응답을 시작하면 프론트 수정 없이 자동으로 실연동 전환됩니다. 구현 → 새로고침 → 동작 확인 루프로 진행하세요.

판정 규칙
HTTP 404/405/501·네트워크 실패·토큰 부재만 "pending" 처리됩니다. 그 외 4xx/5xx는 실제 오류로 그대로 표시되므로, 구현을 시작하면 정상적인 에러 디버깅이 됩니다.
